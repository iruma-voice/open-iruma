## 1. 2025年6月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2025年6月定例会_野口哲次|2025年6月定例会 一般質問通告]]
**テーマ: 立体都市公園のコスト / 分館の不安解消 / 諸証明書発行業務**

* **① 課題の背景**
  狭山台地区近隣公園における立体都市公園の建設について、ライフサイクルコスト（維持・改修・撤去費）への懸念がある。また、分館の統廃合に伴う地域住民の不安や、市役所本庁・コンビニ・地区センター間での証明書発行業務の利用実態の偏りが課題である。
* **② 議員の主張・提案**
  立体都市公園について、必要性やアクセシビリティだけでなく、建設から撤去までの詳細なライフサイクルコストを質し、財政への影響を厳しく監視した。また、分館統合に不安を抱く住民に対する団体交流促進や交通手段の検証を要求。さらに、地区センターの利用促進策（市民課窓口での周知等）を提案した。
* **③ 市側の回答方針**
  立体都市公園は長期的な維持管理費を含めて費用対効果を検証し事業を進める。分館の不安解消については、丁寧な説明と代替の交通手段等で対応する。証明書発行はコンビニ交付や地区センターの利便性を積極的に周知していく方針。

**【分類ラベル】**
* カテゴリ: `公共施設・まちづくり` `行政運営`
* 役割: `行政監視` `課題提起`

## 2. 2025年9月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2025年9月定例会_野口哲次|2025年9月定例会 一般質問通告]]
**テーマ: 西武中建替え等公共施設マネジメント / 外国ルーツの子どもへの支援**

* **① 課題の背景**
  西武中学校の建替え工事費用が約88億円に上り、市の財政再建への影響が懸念されている。また、小中学校において外国ルーツ（外国籍・日本語指導が必要）の子どもが増加しており、支援体制が追いついていない。
* **② 議員の主張・提案**
  西武中建替え費用の内訳と高騰要因を厳しくただし、野田中の既存校舎を活用しない理由を追及。第2期・3期工事費用の再試算を含む公共施設マネジメント計画の抜本的見直しを要求した。教育面では、日本語指導員の人員確保と資質向上、市民団体との連携強化など「誰一人取り残されない教育」を強く提案した。
* **③ 市側の回答方針**
  学校建替えは資材高騰の影響はあるものの、教育環境の維持向上のため計画通り進める。公共施設計画は状況に応じて柔軟に見直す。外国ルーツの子ども支援は、県や市民団体と連携し、日本語指導の拡充に努める方針。

**【分類ラベル】**
* カテゴリ: `公共施設・まちづくり` `教育・多様性`
* 役割: `行政監視` `政策見直しの要求`

## 3. 2025年12月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2025年12月定例会_野口哲次|2025年12月定例会 一般質問通告]]
**テーマ: 学校の熱中症予防と統廃合延期 / 職員の時間外勤務**

* **① 課題の背景**
  猛暑化により児童生徒の熱中症リスクが高まっているが、その対策が確立しないまま宮寺・狭山小学校等の統廃合が進められている。また、市職員の長時間労働（超過勤務）が深刻な課題となっている。
* **② 議員の主張・提案**
  登下校時の暑さ指数（WBGT）による独自の休校基準等の設定を求めるとともに、熱中症予防の支援策が確立するまで、学校の統廃合を「延期」すべきであると強く要求した。行政運営については、時間外勤務の縮減に向けて、事業の棚卸しとDXの積極的な取り組みを提案した。
* **③ 市側の回答方針**
  学校の熱中症対策は国のガイドライン等に沿って適切に対応する。学校統廃合は地域の合意形成を図りながら計画通り推進する方針。職員の超過勤務縮減については、DXの活用や業務のデジタル化（棚卸し）により働き方改革を進める。

**【分類ラベル】**
* カテゴリ: `教育・学校環境` `行政運営・人事`
* 役割: `政策見直しの要求` `課題提起`

## 4. 2026年3月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2026年3月定例会_野口哲次|2026年3月定例会 一般質問通告]]
**テーマ: ジョンソン基地跡地留保地計画 / 市民会館の財政負担**

* **① 課題の背景**
  ジョンソン基地跡地留保地の利用計画において、インフラ整備費用の市負担や民間活力導入の割合に不透明さがある。また、市民会館の移転新設に伴う財政負担が見通せず、整備の目途が立っていない。
* **② 議員の主張・提案**
  留保地計画について、基盤整備への市負担の上限や「賑わい」の再定義を厳しく質し、土地利用計画策定の目標年度を明確にするよう要求した。また、市民会館については、移転新設の目途と市の負担額が明示できなければ、安易な新設を避け「旧市民会館の耐震改修をすべき」と強く主張した。
* **③ 市側の回答方針**
  留保地利用計画は、民間活力を最大限導入し、市の財政負担を極力抑えるスキームで検討を進めている。市民会館の整備については、多額の財源が必要となるため、旧施設の耐震改修を含めゼロベースでの比較検討を継続していく方針。

**【分類ラベル】**
* カテゴリ: `公共施設・まちづくり` `行政運営`
* 役割: `行政監視` `政策見直しの要求`
