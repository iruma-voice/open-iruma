## 1. 2025年6月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2025年6月定例会_細田智也|2025年6月定例会 一般質問通告]]
**テーマ: 中学校の校則公開 / 手話言語条例 / 中高生の居場所づくり**

* **① 課題の背景**
  市内中学校の校則（生徒心得）が時代に合っていないとの指摘や、原則公開されていないことによる不透明性が課題となっている。また、手話言語条例の制定から4年が経過し、デフリンピックを控える中で聴覚障害者への支援体制の更なる強化や、中高生が安心して過ごせる居場所づくりが求められている。
* **② 議員の主張・提案**
  各中学校の校則を原則公開することに対する見解を質し、生徒・保護者を交えた透明性のある見直しを求めた。また、手話通訳者等の確保や条例に基づいた取り組みの成果と課題をただし、中高生の居場所づくりの方向性を提案した。
* **③ 市側の回答方針**
  校則は学校のホームページ等での公開を進め、時代に即した見直しを指導する。手話言語条例に基づく支援は通訳者の育成や情報保障の充実を図る。中高生の居場所づくりは、既存の公共施設等を活用した取り組みを研究していく方針。

**【分類ラベル】**
* カテゴリ: `教育・学校環境` `医療・福祉` `福祉・子育て`
* 役割: `課題提起` `政策提案`

## 2. 2025年9月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2025年9月定例会_細田智也|2025年9月定例会 一般質問通告]]
**テーマ: 自殺対策 / カーボンニュートラル / 起立性調節障害の支援**

* **① 課題の背景**
  第2次入間市自殺対策計画の推進上の課題や、地球温暖化対策（部門別二酸化炭素削減）に向けた具体的な取り組みが急務である。また、教育現場において、朝起きられない等の症状をもつ「起立性調節障害」の児童生徒への理解と適切な対応が不足している。
* **② 議員の主張・提案**
  自殺対策計画の重点施策と推進課題をただし、相談体制の充実を求めた。環境面では、再配達削減による温暖化防止のため、地区センター等公共施設へのオープン型宅配ロッカーの設置を官民連携で進めるよう提案。教育面では、起立性調節障害に対する学校現場の正しい認識と児童生徒への配慮ある対応を強く求めた。
* **③ 市側の回答方針**
  自殺対策は関係機関とのネットワーク強化で支援対象者の孤立を防ぐ。宅配ロッカーの公共施設設置は費用対効果や管理面を含めて検討する。起立性調節障害については、教職員への研修を通じて正しい理解を深め、児童生徒に寄り添った支援を行う方針。

**【分類ラベル】**
* カテゴリ: `健康・医療` `環境・自然` `教育・学校環境`
* 役割: `政策提案` `課題提起`

## 3. 2025年12月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2025年12月定例会_細田智也|2025年12月定例会 一般質問通告]]
**テーマ: 図書館の新たな可能性 / 卒アル制作の教員負担 / 吃音の子どもへの支援**

* **① 課題の背景**
  図書館の利用促進に向けた新たな文化的教材の導入が検討されている。また、卒業アルバム制作における教員の多大な業務負担や価格の高騰が問題となっている。さらに、吃音（きつおん）をもつ子どもに対する健診時の早期発見や、学校現場での支援体制が不十分である。
* **② 議員の主張・提案**
  図書館におけるボードゲーム等の新しい文化的教材の活用を提案した。教育面では、卒業アルバム制作の実態をただし、教員負担の軽減と価格適正化に向けた見直しを要求。保健・教育面では、幼児期からの吃音の発見と家庭支援、およびすべての子どもが安心して声を出せる学校環境づくりを強く提案した。
* **③ 市側の回答方針**
  図書館でのボードゲーム活用等は他市の事例も参考に検討する。卒アル制作は業者選定や内容の見直しにより教員の負担軽減を図るよう指導する。吃音支援は、健診での専門職による相談体制の充実と、教員の理解促進に努める方針。

**【分類ラベル】**
* カテゴリ: `教育・学校環境` `健康・医療` `公共施設・まちづくり`
* 役割: `政策提案` `課題提起`

## 4. 2026年3月定例会
**関連議事録:** [[../00_議事録原本_Raw_Archives/03_一般質問/2026年3月定例会_細田智也|2026年3月定例会 一般質問通告]]
**テーマ: SOGIEへの理解 / ケアプランデータ連携 / 降灰リスクへの備え**

* **① 課題の背景**
  行政運営において、SOGIE（性的指向や性自認）の視点が十分に浸透していない。また、介護事業所の業務負担軽減のための「ケアプランデータ連携システム」の普及が進んでおらず、危機管理面では火山噴火に伴う降灰リスクへの市民の備えが不足している。
* **② 議員の主張・提案**
  SOGIEの視点を行政運営の前提とし、「いるま男女共同参画プラン」への反映と職員の意識改革を要求した。介護行政では、連携システム普及に向けた説明会の実施と定着支援を提案。危機管理では、火山噴火・降灰リスクに関する情報発信と備えの促進を求めた。
* **③ 市側の回答方針**
  SOGIEへの理解促進は各種計画に位置づけ、多様性を尊重するまちづくりを進める。ケアプランデータ連携システムは事業所への周知と導入支援を強化する。降灰リスクへの備えは、ハザードマップ等を通じた市民への啓発活動を推進する方針。

**【分類ラベル】**
* カテゴリ: `人権・多様性` `医療・福祉` `都市基盤・防災`
* 役割: `政策提案` `課題提起`
