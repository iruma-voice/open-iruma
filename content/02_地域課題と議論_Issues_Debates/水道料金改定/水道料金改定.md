##### 3分でわかる！現在の水道料金改定の状況（サマリー）

#### ▶ あなたへの影響
> 「この課題は、入間市内で水道を利用するすべての市民や事業者に、毎月の水道料金および下水道使用料の値上げという形で直接的な家計負担の増加として影響します。一方で、値上げは地震などの災害時にも水が止まらないための老朽管更新費用にも直結します。」

#### 何が起きているのか？（モヤモヤの背景）
入間市の水道料金は、平成11年（1999年）から27年間据え置かれてきましたが、令和8年（2026年）10月より改定（値上げ）されることが決まりました。
主な原因は、市の水道水の約8割を占める「県営水道（県水）」の料金が令和8年4月から約23％値上げされることと、浄水場や配水管などの水道施設の老朽化対策（耐震化工事など）に莫大な費用がかかることです。現状の料金のままでは、令和8年度には水道事業が赤字に転落し、健全な経営が維持できない状況に陥ると予測されています。

### ⚖️ 主な対立ポイント（ずっと議論されていること）

1. **（値上げの不可避性とインフラ維持）**: 市および賛成派は、人員削減やポンプのインバーター制御などの企業努力は既に限界に達しており、安定した給水を続ける（断水を防ぐ）ためには料金改定が避けられないと主張しています。
2. **（物価高騰下での市民負担増への懸念）**: 反対派は、物価高で市民生活が苦しい中での値上げはさらなる負担増になると懸念し、自己水（市の井戸水・伏流水）の割合を増やすことや、一般会計（市の税金）からの赤字補填などで値上げを回避すべきだと主張しています。

### 【時系列】議論の歩みと変遷

### [当初の見通し：値上げは不要との認識]：
本会議：委員会：[2022年03月 都市経済常任委員会]
 
{ 議論のポイント: これまでの経営状況の見直しを行った結果、将来的な値上げの必要性について問われました。}

各者の姿勢:
[[野口哲次]] 議員：給水収益が安定している状況を踏まえ、安定した収入があれば値上げは不要ではないかと確認しました。
🏢 市の回答：当初予想されていた収益の悪化が改善傾向にあり、指標上も要件を満たすため、「見直し後にも水道料金の値上げがなくてもできそうだ」と見解を示しました。（出典：[[2022年3月都市経済常任委員会03月03日-01号(令和4年)]]）

{この発言時点では、過去の企業努力や収益の安定により、当面の間は水道料金の改定を行わずに事業継続が可能であるという見通しが持たれていました。}

### [方針転換：県水値上げ報道による赤字転落の危機]：
本会議：[2024年12月 定例会（第4回）] 一般質問
 
{ 議論のポイント: 埼玉県が県営水道料金を令和8年4月から大幅に値上げするとの報道がなされ、入間市の水道事業への影響が焦点となりました。}

各者の姿勢:
[[内村忠久]] 議員：県水値上げ報道による市水道事業への影響と、事前の情報共有があったかについて質しました。
🏢 市の回答：県から1立方メートル当たり61.78円から76円へ（約23％増）の値上げが示されたと説明。人口減少や物価・人件費高騰に加え、この県水値上げによって「収益的支出が収入を上回る状況の継続が確認されるようであれば、水道料金の値上げはやむを得ない」と、値上げ検討の不可避性を初めて明言しました。（出典：[[2024年12月定例会(第4回)12月05日-05号(令和6年)]]）

{外的な要因（県水の大幅値上げ）が引き金となり、2022年時点の「値上げ不要」という楽観的な見通しから、一転して厳しい財政難と料金改定の検討へ方針が大きく転換しました。}

### [代替案の模索と値上げの確定期]：
本会議：[2025年09月 定例会（第3回）] 一般質問
 
{ 議論のポイント: 令和8年度以降の損益赤字と資金不足の試算が示される中、値上げを回避するための代替案（自己水の活用増や一般会計からの補填）の可能性が議論されました。}

各者の姿勢:
[[佐藤匡]] 議員：自己水（入間川などからの取水）の割合を高めて割安にすることや、一般会計から水道事業への補助・繰入を行って値上げを低く抑えることができないかと提案しました。
🏢 市の回答：自己水の割合は施設能力として全体の約25％が限界であり、取水量を増やせば多額の改修費用と下流や生態系への影響が懸念されるため困難であると回答。また、地方公営企業法の「独立採算の原則」により、一般会計からの補助は考えていないとし、代替案の採用を否定しました。（出典：[[2025年9月定例会(第3回)09月19日-05号(令和7年)]]）

{市のインフラ能力の限界と法律の制約により、議員から提案された「値上げ回避策」は現実的ではないとされ、料金改定が事実上唯一の選択肢として浮き彫りになりました。}

### [料金改定の可決と配慮の要求]：
本会議：[2026年02月 都市経済常任委員会] 
 
{ 議論のポイント: 27年ぶりの水道料金改定を定めた条例案が提出され、値上げの正当性と低所得者への配慮策について最終的な議論が交わされました。}

各者の姿勢:
[[内村忠久]] 議員：老朽化による断水リスクの回避と、県水値上げによる赤字を解消するための不可欠な措置であるとして、改定案に賛成する討論を行いました。同時に、低所得者（少量使用者）への配慮の有無を確認しました。
[[佐藤匡]] 議員：水道料金は所得に対する逆進性があり、物価高で苦しむ一般家庭への配慮が不十分であるとして反対討論を行いました。
🏢 市の回答：現行料金のままではこれまでの経費削減努力も限界に達していると説明。ただし、5立方メートルまでの少量使用者については、改定率を1.07％（現行700円から750円）と低く抑えることで、生活基盤への配慮を行っていると回答しました。（出典：[[2026年2月都市経済常任委員会02月27日-01号(令和8年)]]）

{賛否両論があったものの、将来のインフラ維持という大義名分のもと、少人数世帯への一定の配慮を組み込んだ形で新料金体系へと移行することが決定されました。}

## 今後の見通しと、市民が注視すべきポイント

### 📅 今後のスケジュール（予定）

- **2026年（令和8年）04月**: 埼玉県による県営水道料金（入間市から県への受水費）の値上げが実施
- **2026年（令和8年）05月・09月**: 市から各家庭に向けた「料金改定のチラシ」の全戸直接配布による周知活動（予定）
- **2026年（令和8年）10月**: 入間市の新しい水道料金・下水道使用料の改定（値上げ）が施行予定

### ⚠️ 市民として注目すべきポイント（未解決の問い）

1. **（物価高騰がさらに進んだ場合の再値上げリスク）**: 今回の改定は県水値上げや老朽管更新費の増加を見込んだものですが、今後の資材価格のさらなる高騰や人口減少スピードが想定を上回った場合、再び赤字に転落し、次の値上げ議論が早期に発生しないか注視が必要です。
2. **（広報と市民理解のギャップ）**: 市は27年ぶりの値上げに対して「チラシ配布やホームページで周知する」としていますが、市民生活へ直結する問題であるため、丁寧な説明や低所得者層への継続的なフォローアップが確実に行われるか監視が求められます。

### 【これからの議論のために】

#### ❓ 次の議会で確認すべき問い
今回の議論では、公営企業としての「独立採算」が盾となり一般会計からの繰入は否定されましたが、
[[佐藤匡]] 議員が懸念した「水道料金の体系は所得税と同じように逆進性となっており、値上げは生活が厳しい家庭により重い負担となります」（出典：[[2026年2月都市経済常任委員会02月27日-01号(令和8年)]]）という指摘に対して、市独自で福祉的側面からの水道料減免策などが今後別途講じられる余地はないのか、引き続き議論を深める必要があります。

#### ✅ どうすれば「良い選択」になるか
賛否の二項対立を超え、納得できる着地点の条件を整理する。

| 考え方の軸 | 問いかけ |
| ----- | ---- |
| 負担の公平性 | 世代間の不公平をなくすため、今の現役世代が将来の更新費用を適正に負担するバランスはどこか？ |
| 経営の透明性 | コスト削減の「企業努力」の成果や内訳は、市民から見て本当に十分だと言い切れるか？ |
| インフラと安全 | 料金を低く抑えることで老朽管更新が遅れ、災害時に大規模断水が起きるリスクを市民は許容できるか？ |

> [!TIP]
> 「今回の水道料金を改定せざるを得ない理由として、１つ目は、老朽化した施設を放置すれば漏水事故の増加、水質の低下、さらには大規模な震災時における断水リスクの増大を招きかねません。市民の生命と健康を守るライフラインとして、これらの施設を計画的に更新、耐震化することは最も重要な責務であります。」
> （[[2026年2月都市経済常任委員会02月27日-01号(令和8年)]]、[[内村忠久]] 議員の賛成討論より）

この水道料金改定は、2026年10月の施行まで——そして新しい料金体系に移行した後も——市民が生活と安全の両面から注視し続けるべきテーマです。
