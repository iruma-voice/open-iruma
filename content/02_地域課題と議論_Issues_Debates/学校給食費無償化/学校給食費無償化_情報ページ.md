## 各議論の記録

### 2019年6月定例会（第2回） ─ 吉澤かつら議員

**議事録原本：** [[../../00_議事録原本_Raw_Archives/03_一般質問/2019年6月定例会_吉澤かつら]]

**議論の所在：**
- 幼児教育・保育の無償化（2019年10月実施）に伴い、給食費（食材料費）が保護者負担のまま残されることへの懸念が表明されている。
- 幼稚園・保育所段階での給食費問題を入口として、義務教育段階での給食費の在り方にも言及。

---

### 2019年9月定例会（第3回） ─ 安道佳子議員

**議事録原本：** [[../../00_議事録原本_Raw_Archives/03_一般質問/2019年9月定例会_安道佳子]]

**議論の所在：**
- 「公設公営」方式の維持を求める観点から、給食の民間委託・廃止への懸念を表明。
- 多子世帯への給食費支援策（第3子以降の無償化等）の検討を要請。
- 義務教育無償の原則論を根拠に、給食費無償化の方向性について市の認識を問う。

### 2021年2月定例会（第1回） ─ 永澤美恵子議員

**議論の所在：**
- コロナ禍で休校期間が長期化した際、8月など通常は給食のない月の給食費を追加徴収する動きへの反対。

- 市側の対応と、国の財政支援の動向が焦点となる。

### 2024年9月定例会（第3回）09月18日 ─ 安道佳子議員（一般質問・本会議録）

**議事録原本：** [[../../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2024年9月定例会(第3回)09月18日-05号(令和6年)]]

**議論の所在（登壇質問 ※本会議録 L.1375〜1393）：**

安道議員の登壇質問では、以下の3点が学校給食費無償化の論点として提起されている。

1. **全国で進む給食費無償化は市民の願い**
   - 市民団体が5,089筆の署名を市長に提出したことへの市長の受け止め方を問う。
   - 「他市や都内の記名が見られた」という市長の発言への批判。

2. **「義務教育は無償」を基本に**
   - 憲法第26条に基づく義務教育無償の原則と給食費の関係。
   - 国会答弁（1951年）での給食費無償化への言及と、70年以上実現していない現状。
   - 就学援助制度だけで十分とする認識について再確認を求める。

3. **入間市独自の取り組み検討を**
   - 全国547自治体（30.5%）、群馬県35市町村中32自治体、東京23区、多摩地域5市が無償化・一部補助に踏み出した状況を示す。
   - 入間市でも交付金活用による6か月補助を評価しつつ、多子世帯補助・中学生のみ無償化など段階的なアプローチを提案。

**市長答弁（本会議録 L.1430〜1447）：**

| 論点         | 市長答弁の内容                                            |
| ---------- | -------------------------------------------------- |
| 署名について     | 「海外や他県、他市の署名が数多く入っていた」と認識。当事者（保護者・児童生徒）の意見を重視する姿勢。 |
| 児童アンケート結果  | 給食に一番大切なものを問うアンケートで、「価格」と答えた児童生徒はわずか2%。安心安全・味が上位。  |
| 義務教育無償について | 最高裁判例を根拠に「授業料不徴収の意味であり、給食費は含まれない」との認識を継続。          |
| 完全無償化の費用   | 毎年約5億円の一般財源が必要。現状では継続的な予算確保は困難。                    |
| 独自取り組みについて | 食材費価格の著しい高騰があれば増額分を市が負担することを「前向きに検討」する姿勢。          |
| 国への要望      | 国の責任として財源含め施策を示すべきと引き続き要望する方針。                     |

**再質問の議論（本会議録 L.1725〜1864）：**

- **署名への市長の姿勢**：市長が署名提出時に会わなかったことへの批判。市長は「署名団体の住所問題等で疑義があった」と説明。
- **義務教育無償について（再論）**：全国の無償化実態を前に、「国を待っていたのでは手後れになる」という安道議員の指摘に対し、市長は「引き続き国に強く要望する」とのみ答弁。
- **子ども医療費との比較**：各自治体が独自に進めることで国の制度を後押しした子ども医療費の前例を引き合いに出し、給食費でも同様のアプローチが必要と訴える。
- **東京都の補助制度**：「本来国がやるまでの間、都が補助する」スタンスを示した東京都の対応を例示。
- **市民アンケートの意見聴取について**：2023年6月議会での「何らかの方法でご意見を伺いたい」という市長答弁のその後を確認。市長は「肯定的な意見も多かった」と述べるも、公表状況は不明瞭。
- **タウンミーティングでの声**：市長が開催した各地域でのタウンミーティングで、複数会場から給食費無償化を求める声が出ていたことを指摘。

## 議論における主な論点の整理

> [!note] 凡例
> ここでは、議論の流れを把握するための論点の整理のみを示します。各発言の詳細は、上記の元議事録リンクから直接参照してください。

### 論点1：義務教育無償の原則と給食費の法的位置づけ

- **議員側の主張根拠**：憲法第26条、1951年政府答弁、学校給食法上位法解釈
- **市（市長）側の主張根拠**：最高裁判例（義務教育無償＝授業料不徴収）、学校給食法第11条（食材費は保護者負担）

### 論点2：財源・費用負担

- 完全無償化に必要な財源：年間約**5億円**（市長答弁・2024年9月）
- 地方創生臨時交付金による補助実施：2023年7〜9月・2024年1〜3月（計6か月）
- 市長は「恒久的な財源確保は国の責任」との立場を一貫して維持

### 論点3：全国・近隣市の動向

- 全国無償化自治体数：547自治体・30.5%（2023年度 文科省調査）
- 近隣市の状況：坂戸市・所沢市は無償化実施、日高市は2025年度より無償化方向
- 東京都：都内市町村の8割以上が無償化方向（2024年9月時点の報道）

### 論点4：8月分給食費徴収問題（2023年）

- 通常給食のない8月について徴収が行われた問題
- 安道議員：交付金があるのに徴収はおかしい、と撤回・返金を要求
- 市：制度上の制約・交付金の活用判断として説明

### 論点5：市民要望・署名

- 2023年：市民団体による5,089筆の署名提出
- 市長：「他市・都内の署名が多く含まれていた」と疑念
- 安道議員：署名提出時に市長が面会を断ったことを批判
