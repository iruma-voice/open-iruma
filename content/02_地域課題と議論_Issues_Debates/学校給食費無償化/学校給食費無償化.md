#####  3分でわかる！現在の学校給食費無償化の状況（サマリー）

#### ▶ あなたへの影響
> 「この課題は、小中学生の保護者に、給食費の自己負担額（年間数万円）として直接影響します。」
> 無償化が見送られれば現在の負担が継続しますが、無償化や補助が実施されれば、子育て世帯の経済的負担が大きく軽減されます。

#### 何が起きているのか？（モヤモヤの背景）
全国や県内の近隣市町村で学校給食費の無償化が進む中、入間市では保護者の全額負担（食材費）が続いています。
物価高騰による家計への影響から無償化を求める署名活動も行われましたが、市は「質の高い手作り給食の維持」と「年間約5億円の財源確保の困難さ」を理由に、独自の完全無償化には慎重な姿勢を示しており、国の責任による財源確保を待つ状態が続いています。

### ⚖️ 主な対立ポイント（ずっと議論されていること）

1. **財源の確保と市の役割**:
    - **推進派（議員）**: 国の対応を待たずに、市独自で（段階的であっても）無償化や補助を実施すべき。
    - **慎重派（市）**: 完全無償化には毎年約5億円の一般財源が必要であり、ほかの予算を削る必要が生じるため困難。国の責任で実施すべき。

2. **義務教育無償の解釈**:
    - **推進派（議員）**: 憲法第26条の「義務教育は無償」の原則に基づき、教科書と同様に給食費も無償にすべき。
    - **慎重派（市）**: 最高裁判例を根拠に、無償とは「授業料不徴収」であり、給食費は含まれないと認識。食材費は保護者負担（学校給食法）。

3. **給食の質か、無償化か**:
    - **推進派（議員）**: 経済的な負担軽減（無償化）こそが最大の市民要望であり、子育て支援である。
    - **慎重派（市）**: 当事者である児童生徒は価格よりも「安心安全・味」を重視している（アンケート結果）。入間市自慢の手作り給食の質を維持することが本質的な支援である。

### 臨時交付金による補助実施と8月徴収問題：
会議の出典元ファイルと種類: 🔴 本会議：2023年6月 定例会（第2回）
 
{ 議論のポイント: 地方創生臨時交付金を活用した計6か月の給食費補助の決定と、通常給食のない8月分の徴収をめぐる対立 }

🏢 市の回答： （市長・教育部長）本来は国の責任としながらも、交付金を活用した補助を実施すると説明。8月分徴収については制度上の制約から正当性を主張した。
（参考：[[../../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2023年6月定例会(第2回)06月20日-05号(令和5年)]]、[[../../00_議事録原本_Raw_Archives/03_一般質問/2023年6月定例会_安道佳子]]）

### 全国的な無償化の広がりと市長の明確なスタンス：
会議の出典元ファイルと種類: 🔵 一般質問・本会議録：2024年9月 定例会（第3回）
 
{ 議論のポイント: 市民から5,089筆の署名が提出され、東京都や近隣市での無償化が進む中での入間市独自の取り組みの是非 }

各者の姿勢:

[[../../01_議員名鑑_Members/安道佳子]] 議員： 多摩地域や近隣市で無償化が次々と進んでおり、「国を待っていたのでは手後れになる」と指摘。市民からの署名提出を受け、段階的でも独自に取り組むよう強く求めた。

🏢 市の回答： （杉島理一郎 市長）署名には他市・他県の記名も多く含まれていたと指摘。児童アンケートでは「価格」重視は2%に過ぎず「味・安心安全」が上位であるとし、約5億円の財源を伴う完全無償化よりも「手作り給食の質維持」を優先する姿勢を明確にした。食材料費が著しく高騰した場合は市が負担増を吸収することを前向きに検討するが、基本は国の責任であると答弁した。
（参考：[[../../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2024年9月定例会(第3回)09月18日-05号(令和6年)]]、[[../../00_議事録原本_Raw_Archives/03_一般質問/2024年9月定例会_安道佳子]]）

{市長が「児童アンケートの結果」と「質の維持」を盾に、価格（無償化）よりも品質を重視するスタンスを明確にし、市としての現在の方針が固まった転換点。}

## 今後の見通しと、市民が注視すべきポイント

### 📅 今後のスケジュール（予定）

- **毎年度の予算編成時期**: 物価高騰に対する「市の一定負担（増額分の吸収）」がどのように予算化されるかが焦点となります。
- **国の動向**: 国による学校給食費無償化の法整備や財源措置の議論が進展するかどうかが、入間市の方針に直結します。

### ⚠️ 市民として注目すべきポイント（未解決の問い）

1. **物価高騰時の「著しい食材料費の価格高騰」の判断基準**:
    市長は「著しい価格高騰が発生し質の維持が不可能と判断された場合、増額分を市が負担することを前向きに検討する」と答弁していますが、具体的にどの程度の高騰で市が動くのかは不明確です。
    
2. **近隣市の無償化による「子育て世代の流出」リスクへの対応**:
    日高市や所沢市など周辺自治体で無償化が進む中、入間市が「質の維持」を理由に無償化を見送ることで、子育て世代の定住・転入に悪影響が出ないか注視が必要です。

#### ❓ 次の議会で確認すべき問い
[[../../01_議員名鑑_Members/安道佳子]] 議員が指摘した「国を待っていたのでは手遅れになる」（[[../../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2024年9月定例会(第3回)09月18日-05号(令和6年)]]）という懸念に対し、市は「引き続き国に要望する」と述べるにとどまっており、他市との支援格差が広がる現状への具体的な対応策は未解決です。

#### ✅ どうすれば「良い選択」になるか
無償化推進か現状維持かの二項対立を超え、納得できる着地点の条件を整理します。

| 考え方の軸 | 問いかけ |
| ----- | ---- |
| 財源の確保 | 国の財源を待つ間、例えば「第3子以降」「中学生のみ」など、限られた財源で効果的な段階的支援はできないか？ |
| 質の担保と負担軽減の両立 | 手作りの質を落とさずに、保護者負担額の上限を設ける（超過分を市が負担する）仕組みは構築できないか？ |

> [!TIP]
> [[../../01_議員名鑑_Members/安道佳子]] 議員は一般質問でこう指摘しています。
> 「本来国がやるべき問題であるけれども、待っていたのではめどが立たないので、国がやるまでの間、都として補助すると。（中略）本来国がやるのを待っていたのでは、手後れになりませんかというような気がいたします。」（[[../../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2024年9月定例会(第3回)09月18日-05号(令和6年)]]）

この学校給食費無償化は、国の制度改革が行われるまで——そして市の独自支援の在り方が問われる中——市民が注視し続けるべきテーマです。
