##### 3分でわかる！現在の茶畑テラスの状況

#### ▶ あなたへの影響
> 「この課題は、入間市の貴重な観光財源が『宣伝効果』という目に見えにくい数字に投じられ、結果として維持管理が困難な施設が残るという形で、将来の財政負担に影響します。」

#### 何が起きているのか？（モヤモヤの背景）
入間市が誇る茶畑の景観を活用し、ブランド化を狙って始まった「茶畑テラス」事業。年間約1,000万円の委託料を投じながら、利用者は年間200〜300人程度に留まり、「1人あたりの公費投入額が多すぎる」との批判が絶えません。市は「数千万円の宣伝効果がある」と主張しましたが、設置から3年でウッドデッキの腐朽が進み、事業は「民間移行」の夢から「市による直営（内製化）」という厳しい現実に舵を切っています。

### ⚖️ 主な対立ポイント（ずっと議論されていること）

1. **「実利」か「宣伝」か**: 
    年間の利用人数（実数）の少なさを問題視する議員側と、メディア掲載による「数千万円規模の広告換算額」を強調する市長側の対立。
    
2. **運営の透明性と持続性**: 
    4社の中から選ばれた業者選定のプロセスや、多額の委託料を払い続けることの妥当性。また、老朽化したテラスの危険性と今後の修繕費負担。

### 【時系列】議論の歩みと変遷

### 始まりは「インスタ映え」への期待：
会議の出典元ファイルと種類: 🔵 一般質問：[[../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2022年3月定例会(第1回)02月22日-02号(令和4年)]]
 
{ 議論のポイント: 令和4年度予算に約1,100万円が計上。コロナ禍での新たな観光施策として、茶畑の中にウッドデッキを設置する計画が示されました。}

各者の姿勢:
[[../01_議員名鑑_Members/野口哲次]] 議員： 「この事業に1,000万円をかける価値があるのか。単なる思いつきではないか」と懸念を表明。

🏢 市の回答： 「インスタ映えするスポットとしてメディアに露出し、狭山茶のブランド価値を劇的に高める」と[[杉島理一郎]] 市長自らがその意義を強調しました。

{解説：当初は「民間の活力を呼び込むための呼び水」として、数年後の民間自走を前提に華々しくスタートしました。}


### 1人あたり「4万円」の衝撃：
会議の出典元ファイルと種類: 🔵 一般質問：[[../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2024年9月定例会(第3回)09月05日-02号(令和6年)]]
 
{ 議論のポイント: 令和5年度の決算が示され、委託料998万円に対し、利用者がわずか232人であったことが判明。}

各者の姿勢:
[[../01_議員名鑑_Members/野口哲次]] 議員： 「1組あたり4万円、1人あたりでも数万円の税金が投入されている計算。これは観光事業として成立しているのか」と厳しく追及。

🏢 市の回答： 「NHKの特集で10分放送され、それだけで1,600万円の広告価値がある。現地消費額だけでは測れない効果がある」と強気の答弁を展開。
（参考：[[../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2025年9月定例会(第3回)09月08日-02号(令和7年)]]）

{解説：ここで「実数（利用者）」を重視する議員と、「パブリシティ（宣伝）」を重視する市側の決定的な溝が露呈しました。}


### 市長の「反問権」行使と対立の頂点：
会議の出典元ファイルと種類: 🔵 一般質問：[[../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2025年2月定例会(第1回)02月06日-02号(令和7年)]]
 
{ 議論のポイント: 予算審議において、議論が平行線をたどる中、市長が異例の「反問権」を行使。}

各者の姿勢:
[[../01_議員名鑑_Members/野口哲次]] 議員： 「費用対効果が見えない事業は、即刻やめるべきだ。市民の理解が得られない」

🏢 [[杉島理一郎]] 市長： 「では伺うが、効果がゼロであると言い切れるファクトはあるのか。利用者が1人でもいれば、その人にとっては価値があるのではないか」と逆質問。

{解説：市長が自ら導入した「反問権」を使い、議員の主張に真っ向から反論。議論は政策論を超え、政治的な対立の様相を呈しました。}


### 物理的な「腐朽」と、民間移行の断念：
会議の出典元ファイルと種類: 🔵 一般質問：[[../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2025年9月定例会(第3回)09月08日-02号(令和7年)]]
 
{ 議論のポイント: 設置から3年。ウッドデッキの変色、ひび割れ、腐食が表面化。}

各者の姿勢:
[[../01_議員名鑑_Members/野口哲次]] 議員： 「テラスは無残に傷んでいる。おもてなしの場所としてふさわしくない。潮時ではないか」

🏢 市の回答： 「経年劣化は想定内。安全性に問題はない」としつつも、「民間事業者へ移譲することは難しい。市主体による内製化（直営）を検討する」と方針転換。

{解説：当初目指していた「民間自走」は、施設の劣化と収支の悪化により事実上断念。市が抱え込み続けるという、重い結末が見え始めました。}

## 今後の見通しと、市民が注視すべきポイント

### 📅 今後のスケジュール（予定）

- **2025年度中**: 外部委託から市役所職員による「内製化」への移行検討。
- **2026年度以降**: 老朽化したウッドデッキの本格的な修繕または撤去の判断。

### ⚠️ 市民として注目すべきポイント（未解決の問い）

1. **「直営」でコストは本当に下がるのか**: 
    外部委託をやめ、市職員が予約管理やSNS発信を担うことで、実質的なコストがどれだけ削減できるのか。職員の労働時間が新たなコストにならないか。
    
2. **安全性の担保**: 
    「想定内」とされるテラスの劣化。今後、利用者の怪我や事故が起きた際の責任所在と、修繕にかかる追加の税金投入。

### 【これからの議論のために】

#### ❓ 次の議会で確認すべき問い
- 「内製化にあたり、職員の人的リソースをどれだけ割く計画か。それは他の市民サービスを削ってまで優先すべきことか」
- 「『広告換算額』は、実際の市税収入や茶業者の売上にどう結びついたのか。具体的な相関関係を示すデータはあるか」

#### ✅ どうすれば「良い選択」になるか

| 考え方の軸 | 問いかけ |
| ----- | ---- |
| 財政の持続性 | 宣伝効果という「見えない数字」のために、毎年1,000万円を払い続ける限界はどこにあるのか。 |
| 観光の本質 | ハード（テラス）の維持に汲々とするのではなく、ソフト（体験内容）に投資すべきではないか。 |

> [!TIP]
> [[../01_議員名鑑_Members/野口哲次]] 議員は令和7年9月の質疑でこう述べました。
> 「事業というのは見た目も大事なのです。費用対効果が説明できないものを無理くり続けるというのは、今後やはりいろいろ差し障りがあるのではないか」（[[../00_議事録原本_Raw_Archives/01_本会議_Plenary_Sessions/2025年9月定例会(第3回)09月08日-02号(令和7年)]]）

この茶畑テラスは、老朽化が進むウッドデッキとともに、入間市の観光行政が「見栄え」から「実効性」へと転換できるか——そして撤退の決断を下せるか——を問い続けるテーマです。
