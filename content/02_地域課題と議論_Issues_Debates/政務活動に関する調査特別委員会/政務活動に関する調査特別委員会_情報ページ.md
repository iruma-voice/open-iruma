## 2. 委員会設置の背景・契機

### 2.1 問題となった事案の概要

武蔵藤沢駅周辺土地区画整理事業の清算金問題をめぐり、地域住民が署名活動を行い、市長宛て要望書を提出した。この過程において、**金澤秀信議員（自民党）が紹介議員として関与**したことが問題視された。

具体的な疑義：
- 署名活動で住民に示した「要望書へのご協力のお願い」文書と、実際に市に提出された「要望書」の内容が**異なっていた**
- 1,157名の署名が要望書に添えられたとして提出されたが、署名者が実際に見た文書と提出された要望書が同一かどうか不明
- 要望書作成に議員が主体的に関与した疑い

### 2.2 設置の経緯

都市経済常任委員会の長谷川渉委員長が、金澤議員への事前聞き取りを実施し、その報告を同委員会の協議会で行ったことが発端。報告内容に基づき、議員活動としての不適切性の疑いが浮上し、特別委員会の設置が提案された。

## 3. 調査事項（正式決定）

第1回・第2回委員会で以下の調査事項が決定された。

### 調査事項1
> 署名活動後、議員主導により要望書が作成され、提出されたのではないか

### 調査事項2
> 要望書および署名を利用し、議員倫理上、不適切な政務活動が行われたのではないか

### 調査事項3（後から追加）

**議題：** 請求資料の精査・論点整理

1. 署名活動文書と要望書が異なる場合、要望事項に追加・変更があれば「署名の流用」として問題行為である
2. 本件は署名文書から要望書への要望事項追加があり、署名流用に該当する
3. 誰が行っても問題行為である

5. 主体的に加担していたとなれば、より大きな問題がある

**議題：** 執行部（都市整備部長）への質疑・金澤議員提出メール資料の精査

委員会室内のみでの閲覧（閲覧後回収）という条件でメール資料を確認。

各委員が指摘した疑義：
- **野口委員**：メール内容から「金澤議員が要望書の原案を作成し業者（審査請求人）に渡した」ことが判明→「文書偽造の可能性」を指摘

- **長谷川委員**：
  - 3月22日時点で署名活動の存在を知っていた可能性（メール内容から）
  - 資料4-1だけが他と形式が異なる（スクリーンショットでなく手打ち？）という疑義
  - メールに添付ファイルの痕跡がないものがある
- **鈴木委員**：全体的にメールが抜粋されており、全体の流れが読み取れないとの懸念

**結論：** 疑義が多数残るとして、金澤議員の再招致を次回以降に委員会として要望することを決定

## 5. 調査から判明した主要な事実関係

### 5.1 要望書と署名活動文書の齟齬

| 確認事項 | 内容 |
|----------|------|
| 署名活動で使用した文書 | 「要望書へのご協力のお願い」（回覧板で配布） |
| 市に提出された文書 | 「武蔵藤沢駅周辺土地区画整理事業の清算金に関する要望書」 |
| 両文書の関係 | 要望事項の内容・数が異なる（7項目→3項目に整理等） |
| 金澤議員の関与 | メールのやり取りから、原案作成・修正に積極的に関与したことが判明 |
| 署名者への告知 | 要望書内容が署名時に提示されたかは「不明」（委員会多数意見） |

### 5.2 職員への資料作成強要問題

| 確認事項 | 内容 |
|----------|------|
| 問題となった行為 | 一般質問の前日に資料請求し、職員に「朝までかかっても出せ」と発言した疑い |
| 議員本人の認識 | 参考人招致で資料請求の事実は認めた |
| 委員会の判断 | 複数会派が「議員倫理上、不適切な行為」と評価 |

### 5.3 不動産業者への要望書提供問題

| 確認事項 | 内容 |
|----------|------|
| 判明した事実 | 金澤議員が作成した要望書（原案段階）を、清算金問題に関係する不動産業者に提供していた |
| 都市整備部長の証言 | 業者が議員控室に行きやり取りを文書化し、区画整理課に押印を求めて来たが拒否 |
| 委員会の評価 | 野口委員・長谷川委員が「文書偽造の可能性」「議員倫理上、不適切」と指摘 |

### 5.4 議会事務局の対応問題（調査事項3）

| 確認事項 | 内容 |
|----------|------|
| 問題①：メモの取り扱い | 副委員長（双木議員）のメモ閲覧要求は拒否したが、参考人（金澤議員）には同じメモを提示 |
| 問題②：音声データ削除 | 聞き取り時のボイスレコーダーデータを削除した |
| 問題③：委員長活動の不補佐 | 非公式文書との判断を理由に、委員長の聞き取りメモに基づく質疑を阻止する方向で動いた |
| 委員会の評価 | 4名が「不適切な対応があった」、1名が「なかった」 |

## 6. 委員会内の対立構図

本委員会は、調査の方向性をめぐって委員間で明確な意見対立が生じた。

**「問題あり」側（主）：** 長谷川渉委員（自民）・野口哲次委員（市民フォーラム）・鈴木洋明委員（自民）  
**「問題なし」側（主）：** 永澤美恵子副委員長（公明）  
**中間的立場：** 佐藤匡委員（共産）  

最終的に永澤副委員長への不信任動議が可決されたことで、委員会内の対立が表面化した。
